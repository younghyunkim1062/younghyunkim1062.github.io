추가 설명/공개 범위:

공통 표기
- 각 자료의 시료 형태: 2D monolayer / 3D organoid / 3D skeletal muscle
- 세포주·분화 일수·조건·배치 ID: 확인 가능한 범위에서 기재
- n: 독립 분화 배치, 조직/시료, 기술적 반복을 구분
- 이미지: 스케일바, 채널·마커, 단일 절편/투영 여부
- 영상: 원본 FPS, 픽셀 스케일, 재생 배속, 페이싱·약물 조건(해당 시)
- 그래프: 축과 단위, 정규화, 오차막대 의미, 사용한 통계검정
- 본인 역할: 배양·제작·시료 준비·측정·분석·설계·제작 조율 중 실제 수행한 부분
- 참고자료: 기반으로 사용한 공개 논문/프로토콜 링크와 본인이 조정한 부분

알려진 구분을 유지할 것
- monolayer에서 측정한 FACS/qPCR 결과는 해당 시료 형태로 표시
- 3D 과정에 포함된 초기 2D 단계를 분화 흐름에 표시
- 별도 촬영한 calcium/BF 영상은 각각의 촬영 조건으로 표시
- 개발 중인 장비는 완료·진행 중·계획을 구분
- 비교/개선 사례는 실제 기록에 근거해 작성; 없는 대조군·반복·검증은 채워 넣지 않음
