iCAMAnalyzer

An integrated application for calcium-transient analysis, calcium-based activation mapping, and label-free tissue-motion analysis.

From separate tools to one application

Complementary readouts, connected in one workflow.

I developed iCAMAnalyzer to make functional measurements easier to inspect and compare. The thesis used earlier MATLAB and Python tools; the current Python version integrates calcium analysis and motion analysis within one application.

The 20261021 update reorganizes the interface around input, ROI selection, analysis, and export. Calcium and brightfield remain separate analysis modes.

Calcium kinetics

How does a beat evolve?

Transient timing, duration, decay, and waveform features from fluorescence recordings.

Calcium propagation

How does activation spread?

Calcium-upstroke timing maps and estimates of propagation velocity and direction.

Tissue motion

How does tissue move?

ROI tracking, motion signals, beat features, and image-derived mechanical maps.

Measurement scope: Calcium-derived propagation velocity describes the spread of the calcium signal. Motion and area changes describe tissue movement. Electrical conduction, force, and calcium–contraction timing require appropriate independent measurements or calibration.

My contribution

Development and integration of calcium and motion workflows, region-based analysis, adaptive beat detection, and evaluation of how frame rate, noise, and spatial resolution affect measurement.

Evidence & development status

Testing the measurement, as well as the interface.

My broader analysis work includes synthetic videos with known propagation velocities and checks against experimental recordings. A version-specific quantitative benchmark for this Python package will be documented here.

The 20261021 interface update was smoke-tested with synthetic fluorescence and brightfield videos, including signal extraction and example exports. These checks establish example workflow operation; they do not establish accuracy across experimental conditions. The core analysis files were unchanged from the supplied 20260719 package.

Download & run

20261021 Python source package

This source package contains the Python application, analysis modules, interface assets, dependency list, and an English README.

  • Python 3.10 or later.
  • PyQt5 desktop interface; run in a local Python environment.
  • Fluorescence and brightfield workspaces.
  • Cellpose is included in the dependency list; model inference was not part of the interface smoke test.
Download source ZIP ↓

Quick start

Extract the ZIP into its own folder, open a terminal in that folder, and activate your Python environment.

python -m pip install -r requirements.txt
python iCAMAnalyzer.py

Testing for this UI update used Linux with PyQt5 offscreen rendering. Windows display scaling, experimental recordings, and additional input formats still need verification.
