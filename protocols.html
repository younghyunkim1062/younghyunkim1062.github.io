Protocols

Summaries of protocols and tools developed in the lab. I'm keeping the full step-by-step versions off the public site for now — what's below is the purpose and validated result of each. If you'd like the complete protocol (for collaboration, replication, or licensing), reach out and I'm happy to share.

Full protocol on request

Chamber-Specific Cardiomyocyte Differentiation

Directed differentiation of hiPSCs into ventricular or atrial cardiomyocytes, with a chamber-identity characterization workflow (qRT-PCR: NR2F2, IRX4; immunofluorescence; flow cytometry: TNNT2).

Result: ~97.5% cTNT⁺ efficiency for ventricular cardiomyocytes.

Full protocol on request

iCAMAnalyzer — Calcium-Imaging Analysis

MATLAB App Designer pipeline for ΔF/F₀ normalization, ensemble-averaged transient kinetics, beat-to-beat analysis, pixel-level activation mapping, and conduction-velocity estimation from cardiac organoid calcium imaging.

Result: ~7% error vs. synthetic ground-truth conduction velocity.

Full protocol on request

Multi-Organoid Contraction & Ca²⁺ Imaging Pipeline

Streamlit/Python pipeline for simultaneous 9-well brightfield contraction and calcium imaging analysis, with automated ROI detection and manual correction.

Enables higher-throughput, multi-well organoid screening.

Full protocol on request

Organoid Diameter Analyzer

Custom MATLAB tool for automated organoid diameter measurement from brightfield images, cross-validated against manual measurement.

Validated via Bland–Altman and correlation analysis (GraphPad Prism).

Full protocol on request

3D Skeletal Muscle Tissue Engineering

Fabrication of 3D skeletal muscle tissue on custom scaffolds, with assessment of contractile function and calcium-signal propagation.

Full protocol on request

Microfluidic Chip Simulation Workflow

COMSOL Multiphysics simulation setup for fluid velocity and electric-potential fields in microfluidic chips used for tissue culture and stimulation.
